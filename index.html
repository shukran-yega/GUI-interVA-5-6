About

This is a beta version of the VMan3 Public Portal for processing Verbal Autopsy data. The tool loads verbal autopsy data collected using WHO VA standard instrument, auto-detects which instrument, and allows processing of the cause of death data based on selected algorithm.

Supported Instruments & Algorithms

  • WHO VA V1.5.2 and InterVA5. Source code from here
  • WHO VA 2022 and InterVA6 — python version of InterVA2022 (R-version)
