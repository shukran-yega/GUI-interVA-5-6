Important Notice

This is a beta version of the VMan3 Public Portal for processing Verbal Autopsy data.

• The tool loads verbal autopsy data collected using WHO VA standard instrument, auto-detect which instrument, and allow processing of the cause of death data based on selected algorithm.

Current supported Instruments and algorithms are:

  • WHO VA V1.5.2 and InterVA5. The InterVA5 source code has been copied from here
  • WHO VA 2022 and InterVA6 is a python version of the InterVA2022 (R-version)

• This service is provided "as-is", for research and evaluation purposes only.

• This service does not store any data.
